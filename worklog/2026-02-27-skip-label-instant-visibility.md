# 수직 드래그 시 스킵 라벨 즉시 표시 개선

## 변경 파일
- lib/features/home/presentation/widgets/swipe_classification_card.dart

## 작업 내용
- 위/아래 드래그 시작 시 `위로 스킵`/`아래로 스킵` 라벨이 즉시 보이도록 opacity 계산식을 변경.
- 수직 드래그가 우세한 상태에서 해당 방향 라벨이 최소 가시값(0.55)부터 시작해, 드래그가 커질수록 더 진해지도록 조정.

## 결정 사항
- 스킵 안내는 사용자가 방향을 인지하는 즉시 보여야 하므로, 초기 표시 임계값을 제거하고 최소 노출값을 부여.
