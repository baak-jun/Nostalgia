# 수직 스와이프 방향과 스킵 라벨 노출 위치 정합성 수정

## 변경 파일
- lib/features/home/presentation/widgets/swipe_classification_card.dart

## 작업 내용
- 수직 드래그 시 카드가 실제로 노출시키는 배경 위치에 맞춰 스킵 라벨 노출 위치를 수정.
- 아래로 드래그(카드 하향 이동) 시 상단에 `아래로 스킵` 표시.
- 위로 드래그(카드 상향 이동) 시 하단에 `위로 스킵` 표시.

## 결정 사항
- 좌/우 배경 노출과 동일한 원리로, 수직 라벨도 노출되는 영역에 맞춰 표시하도록 정렬.
