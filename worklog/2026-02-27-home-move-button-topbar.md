# 화면 이동 버튼 상단 재배치 및 스타일 개선

## 변경 파일
- lib/features/home/presentation/home.screen.dart

## 작업 내용
- `화면 이동` 버튼을 본문에서 제거하고 AppBar 우측 액션으로 이동.
- 기본 버튼 대신 `FilledButton.tonalIcon`을 사용해 더 정돈된 상단 액션 스타일로 개선.
- 버튼 모서리와 밀도를 조정해 상단 바에서 과하게 튀지 않도록 정리.
- 하단 `태그 붙이기` 액션은 기존 위치 유지.

## 결정 사항
- 화면 주요 액션(이동)은 상단에 배치하고, 카드 보조 액션(태그)은 하단에 유지하는 구조로 역할 분리.
