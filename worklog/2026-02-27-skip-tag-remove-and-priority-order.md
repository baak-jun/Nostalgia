# 스킵 태그 자동 부여 제거 + 미태그/미보관 우선 노출 정렬

## 변경 파일
- lib/features/home/presentation/home.screen.dart

## 작업 내용
- 스킵(위/아래) 처리 시 자동으로 `스킵` 태그를 붙이던 로직 제거.
- 분류 대상 정렬에서 태그 없는 사진을 우선 노출하도록 정렬 우선순위 추가.
- 기존 정책대로 보관된 사진은 분류 대상에서 계속 제외.
- 같은 조건 내에서는 스킵한 항목을 뒤로 미루는 정렬 유지.

## 결정 사항
- 스킵은 단순 건너뛰기 동작으로 유지하고 태그는 사용자가 명시적으로만 추가.
- 재진입 시에는 미태그/미보관 사진부터 다시 분류 흐름을 시작.
